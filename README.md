## ⚡ Overview

**Surman Code Hub - Wild 8D Portal** is a cutting-edge web authentication template designed to transform traditional login and signup pages into an immersive, next-level interactive experience. It leverages advanced CSS animations, 3D card tilt mechanics, and a dynamic mouse-tracking cosmic universe to deliver striking visual depth and modern aesthetic appeal.

---

## ✨ Key Features

* **🌌 8D Cosmic Parallax Engine:** Fully mouse-driven dynamic background and floating glowing orbs that respond in real-time to cursor movements.
* **📐 3D Interactive Card Tilt:** Smooth perspective transformations that give the authentication card a physical, tactile dimension.
* **🚀 Cinematic Animations:** Custom keyframe animations, including *Laser Zoom* for login mode and *Wild Fly-In* for signup mode.
* **⚙️ JSON-Driven Architecture:** Dynamically managed form fields and branding metadata through a clean, centralized configuration structure.
* **📱 Fully Responsive:** Optimized layout ensuring seamless compatibility across modern screen resolutions and devices.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup & document structure.
* **CSS3:** Advanced Flexbox, Grid, 3D Transforms, Custom Animations, and Backdrop Filters.
* **JavaScript (ES6+):** Dynamic DOM manipulation, event handling, and state management.
